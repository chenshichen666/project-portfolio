# 煤矿巷道支护与吸能锚固技术 · 项目成果集

围绕煤矿巷道围岩控制的三项工程与研究项目成果汇总，含装备结构、力学机理、数值模拟与现场应用数据。

## 项目

| 项目 | 核心内容 | 关键指标 |
| --- | --- | --- |
| 政兴 · 机械式稳阻单体支柱 | DJW 系列全机械支柱，无乳化液、稳定让压下缩 | 稳阻 450 kN，初撑力 ≥60 kN；救援型整机 21 kg |
| 焦煤 · 等效煤柱吸能支护 | 大断面巷道"等效煤柱 / 减跨"控制理念与工业性试验 | 顶底板移近 89–264 mm → 23–55 mm，两帮 67–148 mm → 12–40 mm |
| 华阳 · 高强稳阻吸能锚杆 | 杆体—套筒—轴承钢珠结构，151207 回风顺槽 300 m 试验段 | 恒阻 120–150 kN，单根吸能 ≥100 kJ/m |

## 招投标与项目商务

主笔编制投标文件、竞争性谈判响应书、询价报价文件与项目合同书共 4 份，覆盖公开招标、竞争性谈判、询价采购三类采购方式，
业主方涵盖国有矿业集团、有色金属集团下属矿山、央企科研院所与全国重点实验室；工作内容含资格合规审查、分项报价测算、
技术标编制、谈判澄清与合同条款拟定。
